# 🏎️ Motorsport IQ

**Real-time Formula 1 prediction companion.**

Motorsport IQ transforms live F1 telemetry into interactive gameplay. Users join private lobbies to predict race outcomes in real-time, competing for points and leaderboard dominance.

**Try it Out:** [Motorsport IQ](https://motorsport-iq.vercel.app)

**Watch the Trailer:** [Motorsport IQ - Official Trailer](https://www.youtube.com/watch?v=ph13qlNgtEY)

---

## 🌟 Key Features

- **Live Triggers:** Questions are automatically generated based on real-time race data (overtakes, pit windows, closing gaps).
- **20s Prediction Window:** Fast-paced decision-making synced with the live broadcast.
- **Server Authoritative:** Scoring and resolutions are derived directly from OpenF1 telemetry.
- **AI Explanations:** Every resolution includes a human-like explanation generated by Llama 3.3.
- **Replay Mode:** Practice and demo with accelerated historical race data.

## 💻 Tech Stack

- **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS v4
- **Backend:** Node.js, Express, Socket.io
- **Database:** Supabase (PostgreSQL)
- **Data Source:** [OpenF1 API](https://openf1.org)
- **AI Engine:** [Groq](https://groq.com) (Llama 3.3 70B)

## 🚀 Getting Started

### Prerequisites
- Node.js 22+
- Supabase Project
- Groq API Key

### Installation

1. **Clone the repo:**
   ```bash
   git clone https://github.com/shuknuk/motorsport-iq.git
   ```

2. **Setup Backend:**
   ```bash
   cd backend
   npm install
   # Configure .env (see AGENTS.md for required variables)
   npm run dev
   ```

3. **Setup Frontend:**
   ```bash
   cd ../frontend
   npm install
   npm run dev
   ```
